# Автоматический запуск по времени биржи

С04 ноября2026 расписание задаётся в **America/New_York (ET)**, независимо от
локальных часов Windows и несовпадающих дат перевода часов США/Европы.
По умолчанию: **04:15 ET и16:15 ET**. Утренний скан начинается после открытия
премаркета; вечерний — через15 минут после обычного закрытия основной сессии.

## Обновление существующего задания

Из PowerShell в корне репозитория, после сборки:

```powershell
.\tools\Register-ScannerSchedule.ps1 -AtExchange '04:15','16:15' -WhatIf
.\tools\Register-ScannerSchedule.ps1 -AtExchange '04:15','16:15'
```

Вторая команда заменяет триггеры и аргументы существующего задания
`IbSwingTrader-GetCandidates`. Скан при регистрации не запускается. Одного
обновления executable недостаточно: **старое локальное задание нужно
перерегистрировать**. `-AtLocal` больше не принимается; старые параметры
MorningStartLocal/MorningEndLocal заменены на Exchange-варианты ниже.

Другой executable и ограничение биржевых дней задаются явно:

```powershell
.\tools\Register-ScannerSchedule.ps1 -AtExchange '04:15','16:15' -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -ExePath 'C:\Git_Home\IbSwingTrader\IbSwingTrader\bin\Debug\net10.0\IbSwingTrader.exe'
```

По умолчанию используется Debug/net10.0. Рядом с executable обязателен
agentsettings.json; сборка автоматически не выполняется. По умолчанию доступны
все дни, биржевые праздники/выходные проверяет get-candidates. При заданном
DaysOfWeek день определяется **по ET**, включая пятницу, которая на компьютере
уже может быть субботой. Слоты фиксированы по ET; сокращённая сессия сама по
себе не переносит16:15 на другое время.

## Как удерживается ET

В Windows регистрируются UTC-кандидаты для летнего и зимнего смещений биржи.
Для двух стандартных слотов это08:15/09:15/20:15/21:15 UTC. Обёртка
`Invoke-ScheduledScanner.ps1` сверяет
фактическое ET и запускает приложение только для подходящего слота. Кандидат
другого сезона быстро завершается без запуска приложения/TWS-подключения.
Поэтому NextRunTime в Task Scheduler может показывать служебное срабатывание,
которое не станет сканом.

Допуск по времени — от слота включительно до+5 минут не включительно.
Пропущенный слот позже не догоняется. Время/дата слота сохраняются в
`Data/logs/scheduled-scans/exchange-slots/*.claimed` под общей блокировкой:
повторное ручное/служебное срабатывание того же слота не запускает скан заново.
После ошибки автоматического повтора нет; ручной запуск приложения остаётся
обычной отдельной командой. Часовой пояс Windows скрипты не меняют.

Например, для Афин/Софии04:15 ET соответствует11:15 местного времени в обычные
летние/зимние недели, но10:15 в неделю30 октября2026, когда Европа уже
перевела часы, а США ещё нет. В обоих случаях приложение запускается в04:15 ET.

## Утренняя оценка

После успешного скана, вызванного в **04:00 включительно —12:00 не включительно
по ET**, обёртка запускает evaluate-candidates. Время классификации — начало
вызова, даже если работа закончилась позже или после полуночи. У вечернего
слота автоматической оценки нет.

```powershell
.\tools\Register-ScannerSchedule.ps1 -AtExchange '04:15','16:15' -MorningStartExchange '04:00' -MorningEndExchange '12:00' -WhatIf
# Чтобы оставить только сканирование: добавить -SkipMorningEvaluation.
```

Окно должно лежать внутри одних биржевых суток. Ошибка скана отменяет оценку;
ошибка оценки становится кодом завершения задания. Блокировка удерживается
через обе команды. Оценщик сохраняет свои правила: текущий биржевой день
откладывается, старые планы оцениваются по сохранённым уровням.

## Условия работы и проверка

Пользователь должен оставаться вошедшим в Windows; TWS/IB Gateway заранее
запущен и подключён. Компьютер должен быть включён. `-WakeComputer` включает
попытку пробуждения при разрешённых таймерах сна. Автологина, сохранения
пароля и автоматического запуска TWS нет. Одновременные экземпляры задания
запрещены; обёртки также используют общую файловую блокировку и проверку
уже запущенного executable.

Вывод сохраняется в `Data/logs/scheduled-scans/`: stdout/stderr/status и
отдельные evaluation stdout/stderr. Status содержит биржевое время, ключ слота,
локальный пояс для справки и коды завершения. Регистрация и выполнение остаются
действиями пользователя на Windows; Codex не регистрировал задание из Linux.

Подготовленная проверка без реальных процессов приложения и брокера:

```powershell
.\tests\ScheduledScannerChecks.ps1
```

Она проверяет UTC-кандидаты, лето/зиму, разные недели перевода часов,
независимость от пояса компьютера, утро/вечер, ошибки, переход через полночь,
отключение оценки и повтор одного слота. Реальную регистрацию можно сначала
просмотреть через `-WhatIf`.

```powershell
Get-ScheduledTaskInfo -TaskName 'IbSwingTrader-GetCandidates'
Disable-ScheduledTask -TaskName 'IbSwingTrader-GetCandidates'
Enable-ScheduledTask -TaskName 'IbSwingTrader-GetCandidates'
Unregister-ScheduledTask -TaskName 'IbSwingTrader-GetCandidates' -Confirm:$false
```

Механизм UTC StartBoundary сверён с
[документацией Microsoft](https://learn.microsoft.com/en-us/windows/win32/taskschd/trigger-startboundary).
